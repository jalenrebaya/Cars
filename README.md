# AutoSpot 🚗

AutoSpot is a simple automotive website for cars and car services.

## Features

* 🚗 View available cars
* 🔧 Car maintenance services
* 🛞 Tire services
* ✨ Car detailing
* 📩 Contact form
* 🤖 AutoBot assistant
* 📱 Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
Cars/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
