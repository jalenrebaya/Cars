# AUTOSPOT — Cyber Automotive Experience

A responsive, front-end automotive website concept built with HTML, CSS, and vanilla JavaScript. Vehicle specifications and prices are fictional demo content. Reservation and contact actions only display local feedback; there is no backend and no information is transmitted.

## Files
- `index.html` — page structure and content
- `style.css` — responsive neon/cyber visual design
- `script.js` — mobile navigation, assistant messages, reservation feedback, and contact form behavior

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Four-branch Git workflow
The branches represent development stages. A branch is a Git history pointer, not a separate folder. To make meaningful commits, perform the listed work on that branch and commit the changes before moving to the next stage.

1. `feature/system-setup` — initial project setup, linked assets, semantic page skeleton.
2. `feature/website-structure` — fleet, services, about, contact, and footer sections.
3. `feature/design-functionality` — responsive cyber styling and JavaScript interactions.
4. `feature/final-output` — final validation, accessibility details, and documentation.
5. `main` — integrated final version.

See the provided instructions in the chat before merging: do not merge branches that contain no distinct work, and resolve conflicts if Git reports any.
